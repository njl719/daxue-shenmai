**测试中发现并修复的缺陷:**

1. 同一秒内连续两次备份目录名冲突,后者覆盖前者 → 改为冲突时追加序号。
2. 重新生成计划时新任务 ID 与保留的手动任务撞号,导致"完成"状态错乱 → 任务 ID 加随机后缀。
3. `create_app()` 默认参数为 None 导致启动崩溃 → 显式回退到默认目录。
4. 前端闪卡点击"显示答案"后答案区仍隐藏(重渲染未按状态去除 display:none)→ 修复。

**实测发现并修复的缺陷:**
1. `run_migrations` 仅在 main() 执行,测试与嵌入式入口跳过迁移 → 移至种子之后统一执行(顺序错误曾覆盖种子目录,已修)

4. Service Worker 缓存旧版 app.js 掩盖修复 → 缓存版本号升级机制(daxue-v2)
5. Python 补丁两次将 `

**浏览器实测**:流式对话(检索→生成中·N字→完成·耗时,3.6s)真实状态、工具提案→用户点击→任务实际创建、
