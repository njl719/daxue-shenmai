## 5. 安全态势(实测)

- **认证**:PBKDF2-HMAC-SHA256(600k 轮)哈希存密码,服务端会话(HttpOnly+SameSite=Lax,7 天滑动),登录失败入审计日志(`data/audit.jsonl`);新密码下限 8 位(auth 层两入口统一)
- **数据边界**:`data/`、`backups/`、`exports/` 不入库;个人学习数据不出本机;公网隧道经 Cloudflare HTTPS 中转(用户已知情)
- **密钥扫描**:无硬编码密钥/令牌;云端 AI Key 仅运行时读环境变量;无 `.env` 文件入库
- **输入防护**:上传图片扩展名白名单;注册/提交链接 URL 协议校验;登录/注册限速未做(单实例+强密码下,风险可接受,记录在案)

## 6. 已知限制(诚实清单)

1. **单账号架构**:错题/记录/训练/计划为全局一份数据;多人共用需"邀请码+数据隔离"改造(语义分叉方案 A/B/C 已呈报用户,待决策)
2. **DDG 限流**:单轮仅前 1-2 组关键词稳定返回,已做 3.5s 间隔+24 组关键词按天轮换
3. **知乎/微信部分页面 403**:如实标"仅摘要·日期未核验",不绕过反爬。**小红书/抖音**:无公开检索接口,不下载爬虫插件绕过登录/反爬;通过公开搜索引擎 site: 索引获取公开帖子链接与摘要(需代理出境,代理缺失时该通道如实报失败),另支持用户手动提交链接;GitHub 经官方 API 直连检索公开仓库(元数据含真实更新日期,标注"官方API元数据")
4. **Render 正式部署未完成**:公网目前走临时隧道(重启换网址);Render 注册流程曾受阻于验证码环节
5. **Windows 控制台**:GBK 乱码已在 `run.py` 修复;`server.log` 历史乱码为运行时产物,不入库
6. **CI/本地 Python 版本差**:CI 3.11 vs 本地 3.10(T1 遗留,本轮列入 N3)
