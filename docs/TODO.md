# 定制待办清单(按你的实际情况填写)

系统已可用,但以下信息**只有你能确认**。确认一项就填一项,系统会随之收紧计划。

## 一、考试信息(设置页或直接改 data/settings.json)

- [ ] **考试年份**:目标考哪一年?(如 2027 年 12 月)→ 填入"考试日期"后,仪表盘出现倒计时,计划引擎按剩余时间提示阶段(基础/强化/冲刺)。
- [ ] **数学类型**:数一还是数二?(软件工程多数院校考数一,以目标院校当年招生简章为准)
  - 填好后:大纲中标注"数一为主""数一、数三"的章节(如无穷级数、数理统计、多元积分)按你的类型取舍。
- [ ] **目标院校与专业**:确认初试科目是否正好是"数学+408+英语一"。
  - 若考数学自命题或 408 以外的专业课,告诉我科目名,我可以按同样结构扩展知识库模块。
  - 英语一/英语二确认后,写作/翻译章节的重点可相应调整。

## 二、教材与资料(把示例来源替换成你实际用的)

- [ ] 数学:高数/线代/概率用的教材版本与习题册(如 660、880、1000 题)——录入错题时在"来源"里写清楚,复习时能定位。
- [ ] 408:教材(如王道四件套/天勤)+ 真题年份范围。
- [ ] 英语:真题年份范围(如 2005–2026 英语一)、单词书或 App。

## 三、日常使用节奏

- [ ] 每日可用总时长(默认 240 分钟)与各科配额(默认 90/90/45)——计划页可随时改。
- [ ] 每周复盘日(默认周日)。
- [ ] 阶段目标:现在到考试分几个阶段、每阶段结束想达到什么状态(写在每周复盘的 note 里即可)。

## 四、清理示例数据

- [ ] 熟悉界面后,删除标有"示例可删"的知识点/错题/生词(知识库详情页和错题详情弹窗里都有删除按钮)。
- [ ] 或者一次性重置:`python run.py` 前删除 `data/` 下的 json(先确认 backups/ 里没有你要保留的东西)。

## 五、后续可以让我帮你做的事

- 按你的教材章节顺序,把对应知识点骨架批量填进知识库(你提供教材目录,逐章核对后录入,注明出处)。
- 每周复盘时,把本周错题原因归类统计,生成下周侧重建议。
- 考试日期确定后,把全程计划按"基础/强化/冲刺"三阶段细化到周,再由每日计划引擎落到天。
- 需要时增加"真题套卷模拟"记录类型(现在已有 mock 类型字段,界面入口未做)。
