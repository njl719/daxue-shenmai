## 导入政策

1. **无许可证仓库**:只存来源链接 + 描述 + 核验时间,绝不复制题目/解析全文入库。
2. **可导入内容**必须同时满足:明确开源许可证(允许再分发)+ 字段完整 + 通过
   `来源清单登记 → schema 校验 → 去重(content hash)→ 人工抽查` 流程。
3. 未来如需真题/教材内容,优先路径:用户自录错题(拍照)+ 自己整理的知识点,
   或取得明确授权的数据源。
4. 每条导入数据保存:稳定 ID、来源 URL、许可证、导入时间、最近核验时间、
   内容校验值、人工校验状态(字段已规划,随 P1 题库管线实现)。

## 搜索功能的边界

- GitHub 搜索:公开 API(无鉴权,10 次/分钟限速),结果含许可证徽章提示;
- 招生政策:系统不联网抓取官方站(尊重 robots.txt/服务条款),由用户在「梦校」中
  保存官方链接并自行核验;AI 摘要不得替代官方原文。
