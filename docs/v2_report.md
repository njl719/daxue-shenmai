## 第三步:智能择校与录取概率(已完成,含诚实降级)

- **个人画像** `persona`:默认 2028/11408/数一/英一/408/软件工程/武汉商学院,全部可改(`/api/persona` GET/PUT,年份 2026-2030 校验);
- **月度模拟成绩** `mock_scores`:按月按科真实成绩录入(0-满分校验,拒绝主观评价),画像页可增删;
- **匹配度模型** `match_score`(0-100,四分量:方案适配 40/方向 30/地区 15/数据完备度 15,**逐项解释**);与录取概率**严格分离**——API 与页面两处注明"匹配度≠录取概率";
- **概率模型** `probability`:进入复试(历史复试线均值±σ 的正态CDF)× 复试通过(1:1.2 假设)× → 最终录取;输出初试成绩区间(基于真实模拟的均值±σ)、各科目标、三情景(乐观/基准/保守,标注为假设)、数据覆盖年份、置信度(低/中)、全部假设清单;
- **诚实降级**:复试线年份<2 或模拟成绩不足 → `reliable=false` + 原因清单,系统不编造概率(实测:当前真实数据下即返回不可靠+原因);
- **单调性测试**:分数越高概率不降(模型基本性质)有测试锁定;
- 推荐分层(冲刺/目标/稳妥/保底)仅基于**已采集的官方复试线**+匹配度,无官方数据时 tier=None 并注明——不做无依据分层。
